# Solara app icon

The Solara icon: a gold sun with six spikes and wings on a deep teal tile. These are the final brand
files supplied by the owner (Solara final assets, 2026-11-10). They are committed as delivered and
are **not** regenerated from code.

The Solara name, icon, wordmark and splash are owned by Zee Creations LLC. They are **not**
open source and are not covered by the MIT / Apache-2.0 licence of the code (see `NOTICE` and
`ATTRIBUTION.md`).

## Files

| File | What it is |
|---|---|
| `solara.svg` | The vector master (transparent background) |
| `solara-icon-1024x1024.png` | 1024 px render |
| `solara.ico` | Windows icon (6 sizes, 16–256 px), embedded in the app's `.exe` and used by the MSI |
| `solara.icns` | macOS bundle icon |
| `hicolor/<size>x<size>/apps/ai.storyteller.soundcraft.png` | Linux/FreeBSD icon theme, 16–512 px, plus `scalable/`. The file name is the app id, which changes when the internal names are renamed |

The brand wordmark is in `assets/brand/` and the start-up splash in `assets/splash/`.
